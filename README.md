## 🔄 LeetCode to GitHub Workflow

I use **LeetSync** to synchronize my LeetCode solutions with this GitHub repository.

My workflow is:

```text

          ↓
      Submit Code
          ↓
      Accepted ✅
          ↓
       LeetSync
          ↓
    GitHub Repository
```

This allows my LeetCode practice to be automatically maintained on GitHub.

## 🧠 Problem-Solving Approach

For each problem, I try to follow these steps:

1. Read and understand the problem.
2. Identify the input and expected output.
3. Understand the constraints.
4. Think about a simple solution.
5. Find a more efficient approach when possible.
6. Implement the solution in C++.
7. Test the solution with different cases.
8. Analyze time and space complexity.
9. Submit the solution on LeetCode.
10. Review the solution and learn from it.
